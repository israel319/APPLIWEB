# APPLIWEB

Application web Malaika (AppPlusPlus) — solution .NET dans le dossier `APPLIWEBSMALAIKA`.

## Démarrage

Ouvrir `APPLIWEBSMALAIKA/AppPlusPlus.sln` dans Visual Studio ou exécuter le projet web `AppPlusPlus.Web`.

Configurer les secrets localement via `appsettings.Development.json` (non versionné).
